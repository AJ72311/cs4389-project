This is our Vulnerable Dependencies demonstration! Steps to follow:
  1. Look at the vulnerable versions on the left... they use old releases of Flask, Werkzeug and Jinja2
  2. Read the scan result below them... a scanner called pip-audit found 14 known vulnerabilities in those old releases
  3. These old versions can be attacked in different ways, depending on how the app uses them... for example, crashing the site with specially crafted form data, running code through the debug console, injecting scripts into pages, or leaking one visitor's data to another
  4. Next, look at the patched versions on the right... they are the same libraries, upgraded
  5. Then, read the scan result below them... the same scanner finds no known vulnerabilities, even though our own code did not change
  6. Library versions are fixed when you install them, so this demo has no Switch button
